# Satish — Portfolio

A responsive, single-page portfolio website built with HTML, CSS, and JavaScript.

## Preview

Open `index.html` in a web browser to preview the site locally.

## Personalize it

Before sharing the site, update `index.html` with your own details:

- Replace the sample project titles and descriptions with your real work.
- Change `YOUR_EMAIL@example.com` to the email address where people can reach you.
- Update the About and Skills sections to match your experience.
- Add links to your projects and any other profiles you want to share.

## Publish with GitHub Pages

1. Push the website files to the `main` branch of your GitHub repository.
2. On GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose the `main` branch and `/ (root)` folder, then click **Save**.
5. After GitHub Pages finishes publishing, the site address will appear in the Pages settings.

To upload changes later, run these commands from the project folder:

```bash
git add .
git commit -m "Update portfolio website"
git push
```
